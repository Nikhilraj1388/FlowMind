# FlowMind

AI-powered multi-language code execution visualization platform.

## Project structure

```
dataVisual/
├── apps/
│   ├── web/          # Next.js frontend (Phases 1–2 complete)
│   └── api/          # Express API placeholder (Phase 5+)
├── packages/
│   └── types/        # Shared TypeScript types
├── prisma/           # Database schema placeholder
├── src/              # Legacy Figma/Vite export (reference only)
└── MASTER_PROJECT_DOCUMENTATION.md
```

## Quick start

```bash
cd apps/web
npm install
npm run dev
```

Visit **http://localhost:3000**
