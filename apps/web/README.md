# FlowMind Web

Next.js frontend for FlowMind (Phases 1–2: foundation + UI).

## Run locally

```bash
cd apps/web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

| Route | Description |
|-------|-------------|
| `/` | Landing page (Figma-inspired marketing) |
| `/dashboard` | Project dashboard (mock data) |
| `/workspace` | Editor + visualization + AI panel (UI only) |
